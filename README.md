# 🟡 Pac‑Man Game
![game_icon](https://github.com/PotamsettiSanthoshReddy/pac-man-game/blob/main/game_icon.png)

* A modern recreation of the classic Pac‑Man arcade game, where you control Pac‑Man through a maze filled with pellets, power-ups, and ghosts. The goal? Eat all the pellets, avoid the ghosts, and chase high scores!

## 🛠️ Built With
* HTML & JavaScript

## 🎮 Features
* 🟡 Classic Pac-Man gameplay
* 👻 Ghosts with movement logic
* 💥 Power pellets to temporarily defeat ghosts
* 🧠 Simple AI behavior for enemies
* 🎯 Score and lives tracking
* 🎹 Keyboard controls (arrow keys or WASD)

## 🕹️ How to Play
* Use arrow keys or WASD to move Pac-Man
* Eat all the small pellets to win
* Avoid ghosts — unless you’ve eaten a power pellet
* The game ends when you lose all your lives
